  2. 04/09/26

    prototype components

    • Asked Mr Scarlett for a Raspberry Pi 3, but it wasn't a match for the project.

  3. 06/09/26

    choosing a battery

    • Considered sodium-ion versus lithium-ion batteries for the prototype and planned to ask Mr Ray for advice.
    • Decided to use lithium-ion for the prototype, with the possibility of creating a sodium-ion controller later.
  4. 20/09/26

    hardware and servers

    • Hardware: Parts finally arrived! two components needed to share a 5V boost converter, and a breadboard was needed to test everything properly (which i didn't have). Planned to ask the CS department for a breadboard and jumper wires.
    • Software: Configured the ESP32 to display pictures on a local web server. It works really well, but the esp-32 is so freaking hot when it runs.
  5. 28/09/26

    adjustments and voltage

    • Software: Wrote ESP32 code to work with the PIR and DHT22 sensors and trigger on PIR detection. Claude helped me, and the code was based on this ESP32-CAM photo and timestamp tutorial.
    • Hardware: Mr Ray and I soldered the TP4056 charge controller to the MT3068 step-up converter to provide stable 5V for the ESP32. I snapped off the solder connection when adjusting the output voltage (had to turn that tiny knob for ages), so I planned to meet with him again the next day. Gonna flash the ESP32 code in the meantime.
  6. 08/10/26

    breadboards and birds

    • Some exams coming up so progress has been slow.
    • Hardware: Used breadboard and circuitry works! Needed to resolder the charge converter for a better connection. Borrowed soldering iron and didn’t burn myself luckily. Circuitry worked and everything was powered! However there was an error with the led and the temperature sensor sharing the same pin. Will resolve.
    • Software: continued writing for the website that you’re on right now! Added development page and some more birds for the dictionary.
